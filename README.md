# coordinateTBI

coordinateTBI is a personal project that was born out of a friend's desire to have a planning and management tool for activites that are organized by the Triangle Baha'i Institute. The project is intentionally organized as a small full-stack system so that I can separate different concerns into layed boundaries. 

At a high level, the system has the following mving parts:
- A React frontend in frontend/
- A FastAPI HHTP adapter in api/
- Shared Python domain code in core/
- Supporting development infrastucture in .devcontainer/
